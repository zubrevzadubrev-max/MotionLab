Основные виды движения

Механическое движение — это изменение положения тела относительно других тел с течением времени.

→

Равномерное движение

Тело за равные промежутки времени проходит одинаковые расстояния. Скорость остаётся постоянной.

x = x₀ + vt
⇈

Равноускоренное движение

Скорость тела изменяется на одинаковую величину за равные промежутки времени.

x = x₀ + v₀t + at² / 2
⟳

Движение по окружности

Тело движется по круговой траектории. Направление скорости постоянно изменяется.

v = ωR
